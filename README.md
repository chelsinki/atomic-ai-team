# ART — 原子化重组 / Atomic Restructuring Team

> **AI 原生交付的人机混合架构 · Human-AI Hybrid Architecture for AI-Native Delivery**

---

## 概述

本仓库整合了围绕 **Porsche CCP ART 重组** 的研究成果，形成一个 **AI 原生交付的开放框架**。核心主张：

> **将传统 5-9 人 Scrum Team 拆分为 3 人原子小队（Solution Lead + AI Engineer + Harness Master），通过 N 个 AI Agent 实现产出倍增。同样的人，做更多的事——增效不降本。铁三角 = PO → Dev → SM 的 AI 时代极简版。**

## 核心概念

### 三角色（AI 时代铁三角）

| 角色 | 传统对应 | 核心职责 |
|------|---------|---------|
| **Solution Lead** | PO / BA | 问题定义、需求澄清、价值判断、验收 |
| **AI Engineer** | Dev | AI Agent 编排、代码实现、工具链搭建 |
| **Harness Master** | SM / QA | 流程治理、质量门、隐性知识蒸馏、过程护栏 |

### 四层提效模型

1. **Squad 层** — 局部提效（3人 + N Agent）
2. **Value Stream 层** — 流动提效
3. **ART 层** — 协同提效
4. **Portfolio 层** — 战略提效

### 方法论来源

- 德勤 GDC 参访（2026-05-08）"未来三角色"模型
- 11 家前沿 AI 公司组织模式研究
- Agentic AI Con 2026 精华整合
- 四层赛马与协作平衡框架
